# ADR 0021: L4 会话监督、空闲策略与登录边界的首版实现

- 状态：proposed
- 日期：2026-10-17
- 决策者：架构组与安全审查者（待人类评审）
- 批准记录：待补
- 关系：细化 ADR 0013、0015、0018；不改变分层、配置格式、协议 XML 或认证机制。0019/0020 编号由进行中的多输出/缩放工作占用。

## 背景与备选

L4 三个 crate 原来都只记录启动日志并立即退出。PRD 的 S01/S05 要求真实进程监督与有限清理；S03 要求从合成器接收空闲通知，并在可信锁完成后才能允许挂起。

备选包括继续保持骨架、一次接通系统认证/挂起、先实现不改变授权面的监督与纯策略。选择第三种。一次接通认证违反 ADR 0015 的前置审查要求：合成器尚无安全锁屏实现，认证 helper、凭据传递、权限和恢复路径也尚无批准记录。不能以此提案或一个成功的测试桩替代批准。

本次只新增向下的 Cargo 依赖：L4 → `inox-common`、`inox-config`、`inox-protocols`；没有 L4 横向依赖，没有新的第三方 crate、配置 schema、私有 IPC、网络监听或系统认证依赖。calloop、Rustix、wayland-rs、Iced、thiserror 都复用工作区已有版本。

## 实现范围与生命周期

### inox-session

- 固定两级运行时依赖图：合成器 → 桌面子进程。通过 `wl_display.sync` 的真实回复确认合成器可响应，不能以 socket 文件存在代替。
- Shell 当前是一次性配置/注册表检查进程，成功退出即完成；面板是必需常驻项；壁纸、通知、空闲监视为可选项。启动器、设置由交互入口按需启动；greeter 位于登录前，不作为已登录会话的子进程。
- 默认从自身所在目录启动同一安装组合的二进制；`--bin-dir` 用于显式选择组合。`--headless` 只传给合成器，默认仍选择真实后端。启动等待上限 5 秒。
- 每组件在滚动 60 秒内最多 3 次自动重启，退避为 250/500/1000 毫秒；替换进程启动失败同样消耗预算。可选项耗尽后停止重试并记录退化；必需项耗尽则结束会话。
- 每个子进程有独立进程组。旧进程退出后终止其残留进程组，再允许重启。此保证针对未主动脱离进程组的桌面组件；未来支持双重 fork/自行 setsid 的服务需要受审查的 cgroup 归属，首版不声称覆盖该情况。
- `SIGINT`/`SIGTERM` 和有限运行到期触发退出：先逆序通知依赖组件，4 秒后对未退出组件升级 KILL，依赖全部退出或到 5 秒后通知合成器，8 秒后对合成器升级 KILL。通过 `try_wait` 回收直接子进程；不可中断内核等待不属于用户态可保证的 10 秒上限。
- calloop 使用 signalfd，其屏蔽状态跨 exec 继承。内部 `--exec-child` 在子进程中解除会话信号屏蔽后使用安全的 `CommandExt::exec` 替换自身，避免普通 UI 忽略注销信号，不引入 unsafe/pre_exec。
- 验证运行时根目录绝对、当前用户所有且无组/其他用户访问权限，在其中创建独占的 0700 子目录；只清理拥有的已知 socket/lock 文件和空目录，绝不递归删除其他内容。子进程的显示环境由 session 覆盖，清除父会话的 `WAYLAND_SOCKET` 和 `DISPLAY`。
- 环境配置在会话启动时加载；SIGHUP 明确记录该状态不支持会话级热替换，不终止会话或盲目向合成器转发。各组件的配置重载仍由组件自身负责。
- 合成器退出一律结束会话并说明连接不可恢复；不重启合成器并声称恢复原窗口。
- **只报告 compositor ready。** L3 尚无服务就绪握手，启动进程不能证明核心入口和输入已经可用，因此不发送完整 session ready 声明。

### inox-idle

- 从 `inox-protocols` 获取 `ext-idle-notify-v1` 绑定，绑定 v1 `get_idle_notification`，由服务端落实 idle-inhibit；不采用忽略抑制器的 v2 input-only 通知。
- calloop 处理 Wayland fd、退出信号与启动超时；发现缺少 seat/notifier、移除选中全局或断开连接时显式失败，不使用进程/输入轮询。
- 单 seat 首版选择第一个 seat；不声称支持多 seat。默认阈值 300 秒，CLI 可显式修改；不增加配置文件格式。
- 纯策略覆盖自动/手动锁定、抑制、带代次的锁确认、5 秒超时和失败。抑制不阻止手动锁定；活动恢复不解锁；仅当前且未过期的可信确认能允许对应挂起。已锁定时也要求本次准备的确认。
- **真实锁定与挂起未接线**：收到 idled 后明确告知自动锁不可用，不能把启动 `inox-lock`、进程成功退出或策略返回值当作锁完成。不会执行 suspend 命令，也没有声称已取得 logind 挂起抑制锁。

### inox-greet

- 登录模型包含不可用、就绪、认证中、会话启动中、失败和已启动；匹配认证代次后才允许返回启动请求，等待 display manager 的启动回执后才进入已启动。
- 验证并限制账户名，取消清理身份；30 秒无响应取消当前会话，重复/旧/超时成功不会启动；滚动 60 秒最多 3 次尝试，取消不重置预算。
- 模型不存储密码。默认二进制以失败状态解释认证边界未获批准；只有显式 `--preview` 打开 Iced 预览，登录按钮禁用，不采集凭据，也不执行会话命令。
- 预览提供 en-US/zh-CN Fluent 文案、主题令牌、字体缩放、滚动以及键盘 Tab/Shift+Tab、Enter 和 Escape 操作。离屏渲染不是安全登录表面证据；AT-SPI 桥和真实 greeter 宿主未验证。

## 验收、迁移与回退

CI 的每 crate 分片运行单元、真实子进程与协议边界测试：重启预算、静默 Wayland peer 超时、必需/可选项失败、合成器退出、正常注销信号继承与目录清理；idle 的真实 Wayland 线协议事件/缺能力拒绝；登录的过期、乱序、重复和限流路径；预览的双主题/双语言/200% 字号像素与截图。

另加 `L4 headless session` job：在私有 XDG 配置和 `dbus-run-session` 下运行真实 Inox headless 合成器及 L3 子进程，确认合成器往返与有限注销。它只提供 S01/S05 的部分进程生命周期证据，不证明完整 session ready、故障后应用保留或 S02/S03 安全性。E3 中保留客户端、注入崩溃并验证连接不丢失仍需后续完整场景。

没有磁盘 schema/协议变更，回退为卸载这一组合或切回上一 CI 发布物，不需要配置迁移。CI 未通过前不宣称完成；E4 真机、认证、锁屏与挂起验收不由上述用例替代。

## 未决事项与后果

可运行的监督和可测试策略让 L4 不再是空骨架，但**不构成 M5 完成**。架构组与安全审查者需要在真实认证/锁屏/挂起实现前决定并批准：系统认证服务、helper 许可证与最小权限、可信连接/能力传递、凭据销毁、greeter 宿主、锁完成确认及 logind prepare-sleep/delay inhibitor 时序。需要新增协议或依赖时另提实施 ADR；本提案未授权。

后续完整 session ready 还需要 L3 的真实就绪/请求回执。将来增加多 seat、后台脱离进程组、XWayland DISPLAY 环境发布、用户自启动或 systemd/cgroup 管理时复审本 ADR；不能无声扩大首版固定图的承诺。

# ADR 0026: 运行中配置重载与逐消费方确认

- 状态：proposed
- 日期：2026-10-17
- 决策者：架构组（待人类审查）
- 关联：ADR 0009、0013、0014、0018、0024；PRD C02、C03、D04。

## 范围

沿用现有 TOML、Cargo 分层、calloop 和组件状态所有权，不新增 crate，
不修改现有 Wayland 请求或事件。使用标准会话 D-Bus 承载附加的配置接口；
所有权威 schema、校验及语义快照仍在 inox-config，传输在消费方二进制内。
不引入 L3 到 L2 或同层 Cargo 边。复用工作区已有 zbus（MIT）与 calloop
（MIT）版本；Iced 消费方通过消息应用，合成器通过 calloop 通道应用。
这是兼容的增量能力；本提案不将其它 proposed ADR 自动标为 accepted。

## 契约

接口规范见 `crates/inox-protocols/protocol/configuration-v1.md`。
每次调用携带客户端代次和完整候选语义快照，回执来自消费方应用后的状态。
同一消费方串行处理，不以读盘成功代替应用成功；客户端超时仍为未确认。
SIGHUP 通过 calloop 信号源触发相同入口，失败 warn 并保留上一份状态。
读取、壁纸准备与解码不在 UI/合成器事件循环中执行。
设置把 Shell 家族拆成面板、启动器、壁纸三个请求，汇总其实际结果。

根配置的 environment 只影响子进程启动环境；输出模式、位置和缩放需要服务端
试用/确认/回退才适合实时切换。本次对这些变化明确拒绝热应用，不报告成功，
保留文件供后续会话读取。输入法命令行选择保持优先；动态引擎切换需要保留
专用连接授权、退出清理和失败恢复，不能用普通应用连接替换。

## 验收

CI 覆盖语义快照、重载失败保留状态、真实 D-Bus 请求/回执、陈旧代次、
组件不可用及资源失败。已有窗口、任务列表、通知、查询等运行状态不得因
重载整体重建。真实显示与背景层摆放沿用原有证据边界，不由配置回执推断。

## 备选与后果

只发信号不能让设置区分已保存与已生效；文件监控也不能关联当前保存代次。
在 L1 添加 IPC 或创建公共运行时 crate 会扩大依赖与架构范围，因此消费方各自保留
小型二进制传输桥，沿用既有的 Iced/运行时边界。代价是几份相似桥接代码与按进程的
总线连接。设置未运行时，信号与命令行入口仍可使用。

当 layer-shell 宿主、实时输出试用回退或输入法原子替换落地时复审限制；
若需要跨用户、远程配置或跨进程强一致事务，须独立设计权限与提交协议。

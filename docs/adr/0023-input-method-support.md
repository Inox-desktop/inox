# ADR 0023: 提前接入桌面输入法

- 状态：proposed
- 日期：2026-10-17
- 决策者：架构组
- 批准记录：待人类评审；当前开发会话要求提前实现输入法支持，不视为本 ADR 已获架构接受。
- 关联：ADR 0006、0012、0015、0022；PRD §2.3。

## 背景与范围

PRD 原将输入法安排在 1.0 之后。按当前开发会话要求，提前实现标准
`text-input-v3`、`input-method-v2`、`virtual-keyboard-v1`，覆盖应用文本上下文、
预编辑、提交、删除周边文本、键盘抓取、候选窗及焦点/退出/锁屏生命周期。
不新增 Inox crate、不改变分层或私有 IPC、不链接输入法引擎。
设置的持久化启动偏好是后续增量，见 ADR 0024。

维持原排期会让中文等文本输入长期不可用；只依赖 GTK/Qt 模块不能覆盖原生
Wayland 应用；直接广告 Smithay 0.7 的管理器不能独立解决过期提交、重复实例、
锁屏抓取和候选窗放置。因此协议绑定仍经 inox-protocols，座席、输入与绘制
仍使用 Smithay，合成器显式管理文本事务和生命周期。

## 决策

- 应用端 v3 和服务端 v2 的接口版本均为 1。提交序号使用 wrapping 算术，
  输入法的编辑结果在匹配最新 done 的 commit 到来前不发送给应用。
- 合成器拥有焦点、活动文本对象、输入法实例、候选表面和抓键状态。
  每个座席只有一个输入法；第二个对象收到 unavailable，销毁它不影响原对象。
  所有属于焦点客户端的文本对象收到 enter/leave；禁用、失焦、销毁均清理组合状态。
- 输入法通过显式 `--input-method <EXECUTABLE>` 或用户保存的 `[input] input_method` 启动；
  命令行优先，配置默认空，headless 后端只读命令行。命令行参数逐项传递
  `--input-method-arg <ARG>`，不使用 shell。用 Unix socket pair 将子进程 stdin
  作为 `WAYLAND_SOCKET=0` 传递，服务端连接带合成器设置的权限标记。
  普通监听套接字上的连接没有该标记；不按 PID、进程名、app_id 授权。
- 输入法进程由 calloop 定时器监督；失败有界重启，退出时终止并回收。
  启动失败记录错误，保留普通键盘输入；不默认启动或下载引擎。
- 锁屏从接受请求起取消输入法抓键，移除文本焦点，隐藏候选窗并拒绝虚拟按键。
  已绑定的旧对象同样受约束；解锁后重新同步。输入法不可读取锁屏密码。
- 候选窗跟随活动表面光标矩形，以全局逻辑坐标放置，向上翻转/钳制在对应输出；
  绘制按该输出 scale 换算物理像素。鼠标点击候选窗不抢应用键盘焦点。
- 外部 Fcitx5/IBus、GTK/Qt 模块与 XIM 是用户安装的进程，不成为核心依赖。
  XWayland 通过对应引擎的 XIM/工具包模块工作，不声称 text-input-v1/v2 已支持。

## 验收与回退

inox-compositor 的真实 Unix socket 客户端测试覆盖中文预编辑/提交、删除、
上下文、序号、多个文本对象、焦点、重复实例、断连恢复、抓键、普通客户端权限
与锁屏拒绝；候选窗以软件渲染像素验证位置和缩放。协议绑定测试锁定接口版本。
CI 是唯一验收入口，本地 fmt/check 仅作参考。另设 Fcitx5 拼音 CI 任务，
使用发行版外部进程验证真实 nihao 预编辑与 你好 提交，关闭云拼音等联网插件。

仅使用命令行时移除启动参数即可停用；使用设置保存的偏好时清空
`[input] input_method`。旧程序会拒绝该新键，降级时先删除它，见 ADR 0024。Fcitx5/IBus 与 GTK/Qt/
XWayland 的真实桌面验收尚需人类使用 CI 产物逐项记录；没有该证据时只声明
协议实现待验收，不将测试输入法替身当成外部引擎兼容证明。

## 后果与复审

提前提供多语言输入基础，增加合成器协议状态机与进程管理维护成本。新增依赖
wayland-protocols-misc 为 MIT，已在 Smithay 的依赖图中，此处增加直接绑定出口。
引擎选择面板、托盘状态、自动安装以及旧版 text-input 需要独立产品需求；
未来升级协议或修改授权/锁屏边界时重新评审。性能由事件驱动，子进程监督每秒
一次且重启有界；此为实现策略，尚无性能测量结论。

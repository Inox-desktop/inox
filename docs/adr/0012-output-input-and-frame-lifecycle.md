# ADR 0012: 输出拓扑、窗口焦点与帧调度采用显式生命周期

- 状态：proposed
- 日期：2026-10-16
- 决策者：架构组（待人类评审）
- 批准记录：待补
- 关系：扩展 ADR 0005 的 headless 路径；收紧 ADR 0008 与真实后端提案的产品契约，不预先批准其具体 API 或 unsafe 清单

## 背景

ADR 0005 验证了离屏纯色帧，ADR 0008 定义了窗口/布局/注入输入。它们尚不能说明：输出断连后窗口放哪里、离线屏的面板偏好是否保留、按键跨焦点时如何释放、没有 damage 时是否持续绘制、首帧和 VT 恢复如何启动。仅给出 `RenderTarget` 接口或 vblank 回调不足以回答这些问题。

PL-02 的面板焦点测试、PL-04 的输出映射恢复与 PL-05 的分辨率/无屏保存测试为行为边界提供参考，见 [Plasma 对照](../quality/plasma-reference.md)。它们不是 KWin 的后端实现证明。本 ADR 的 DRM/输入约束来自 Inox 自身目标，具体实现仍必须以锁定 Smithay 版本的 API 和 CI 原型验证。

依据：PRD §2、§8、§9、§13；AGENTS.md §3、§4、§6；[验收规范](../quality/acceptance.md) W01–W05、O01–O04。

## 上游核验依据

已读取本机 Cargo registry 中 Smithay 0.7.0 的 `src/backend/session/mod.rs` 与 `libseat.rs`，并与[上游 session 文档](https://docs.rs/smithay/0.7.0/smithay/backend/session/index.html)、[LibSeatSession 源码](https://docs.rs/crate/smithay/0.7.0/source/src/backend/session/libseat.rs)对应：`Session` 是 trait，libseat 实现由 `LibSeatSession::new()` 返回 session/notifier；notifier 接入 calloop。该版本的模块说明仅提供 libseat 实现，不能据此写出 `Session::auto()` / `Session::Direct` 或由 Inox 强制指定的回退顺序。

这只核实 session 接口，不代表本次已经验证 DRM/GBM/libinput 的全部调用或系统依赖。真实后端实现前仍需逐项盘点锁定源码，记录单位、所有权、安全 API 与生命周期；只在确需 FFI 时提议最小 unsafe。

## 备选方案

| 方案 | 收益 | 代价 / 结论 |
|------|------|-------------|
| 保留所有输出映射到原点，只按 connector 序号索引 | 实现少 | 双屏重叠、枚举变化丢偏好，不能作为 M4 产品模型 |
| headless 与 DRM 各维护一套窗口/焦点规则 | 后端可独立推进 | 同一用户动作在两条路径行为不同，测试无法覆盖真实规则 |
| 统一逻辑状态，后端只提供设备与呈现边界 | 可测、语义一致 | 状态迁移和错误处理更复杂；选择本方案 |
| 定时器持续绘制，或仅等待 vblank | 易接入 | 前者浪费空闲资源，后者无法独自启动首帧/恢复帧，均不能单独作为完整调度策略 |

## 决策

### 状态所有权与坐标

- `inox-compositor` 唯一持有输出拓扑、工作区、窗口生命周期、seat 焦点、输入 grab 与锁定状态；Shell 订阅快照/变更并提出请求，不维护第二套权威窗口状态。
- 运行时输出 ID 与持久化显示偏好 ID 分开。输出拔插只结束运行时实例，不删除偏好；偏好匹配综合设备/连接信息与可用显示标识，不把 connector 数字序号、列表下标或 EDID 序列号视为永远唯一。缺失/重复标识采用明确回退与用户覆盖，并测试重排/歧义场景。
- 统一使用有符号逻辑全局坐标，输出具备位置、mode、scale、transform、usable area；物理像素转换在后端边界执行并定义舍入规则。M4 至少支持异构分辨率、负坐标、100%/200% 整数缩放与 90° 旋转；分数缩放在协议与像素测试完成前仅为扩展配置。
- 窗口 map、unmap、destroy 分离；未提交有效缓冲不算可见。configure/ack 与客户端尺寸约束通过 Smithay/协议语义处理，不以内部列表存在等同于已显示。

### 拓扑变更与故障

1. 新拓扑先校验几何、设备可用性与可支持的提交，再尝试应用；失败恢复上一可用状态并报告，不能只在内存中标记成功。
2. 用户的显示试用变更必须在 15 s 内确认，否则恢复；超时逻辑由服务端维持，设置窗口退出也会生效。拔插是设备事件，不能等待人类确认才迁移可操作入口。
3. 输出断连时迁移窗口和入口到存活输出，保留离线屏偏好；重连不得重复创建面板。运行时临时重排不覆盖持久化用户布局。具体写盘归属见 ADR 0014。
4. 全部输出消失时保留会话与客户端连接、停止无意义重绘并等待设备事件；设备重新出现后重新调度。libseat pause 时停止设备提交和派发，resume 时重建设备状态、清理陈旧输入并重绘；VT 归属释放/恢复必须在 M2.5 真机验收，不能只登记接口后延期。
5. 桌面启动若明确请求 DRM，设备不可用应失败并给出诊断；生产会话不能静默回落 headless 后报告 ready。headless 只能由测试/调用者显式允许；`auto` 探测也不能把无可操作输出等同于可用会话。

### 输入与焦点

- 键盘、指针、触点各有独立焦点/生命周期；首版支持的键盘/指针必须正确处理 enter/leave、按下/释放、repeat、修饰键、能力增删及焦点对象销毁。暂不支持的设备能力不广告为可用。
- 同一 seat 的键盘焦点至多一个；焦点转移与快捷键消费形成单次决策，未消费事件只发送给正确客户端。popup grab、拖放 grab 与 session lock 的优先级必须测试，不用 UI 自报“已关闭”代替合成器释放 grab。
- 指针绘制与输入分发一起交付。硬件光标不可用时需可验证的软件光标路径；只更新命中点但无可见指针不算真机输入完成。
- M2 的确定性 US keymap 是测试配置，不能演变为覆盖用户设置的产品限制。配置生效/失败需回执；真实设备事件转换只进行一次，具体 keycode 偏移以所锁 API 的单位与事件测试为准，禁止凭猜测重复转换。

### 帧调度与资源

- 每个输出至少区分 idle、scheduled、submitted、paused/removed；首帧、damage、输出恢复触发调度，提交完成/呈现事件结束 pending。vblank 是节拍/完成输入之一，不能作为唯一能唤醒首帧的事件。
- 无 damage 不提交无变化帧；必要的 frame callback 与 presentation feedback 按协议语义反馈，不能为了省帧永久饿死客户端。headless 使用可控时钟/定时源表达同一逻辑，不伪造真实物理呈现时间。
- 每输出最多保留受控数量的 pending 提交，提交失败区分可重试/设备失效；重试有边界，不阻塞 calloop。热插拔/暂停后完成的旧事件带代次校验，不能复活已移除对象。
- 通过 Smithay 现有 DRM/GBM/输入/session 抽象实现，不自研底层替代层。先盘点安全 API，再逐处审查确实必要的 FFI；不能按文件数量预先批准 unsafe 或假定上游构造函数签名。

## 验收、落地与回退

最小 CI 原型要证明首帧、空闲、damage、提交失败、pause/resume、移除后旧事件等迁移；E1 状态机与 E2 真实客户端共用窗口/输入规则，E3 验证 Shell 跟随输出变化。E4 完成 O01–O04、H02 对应步骤，编译真实 feature 不能代替运行。

M2.5 交付单屏真机闭环、VT 和可见指针；M4 完成多输出/布局/显示试用。每步都保持 headless 回归；实际 Smithay API、feature、session 选择及系统依赖以实现 PR 的锁定源码证据审核，本提案不声称 `Session::auto()` 或任意特定构造函数存在。

回退时恢复上一可用拓扑/配置代次；若设备不可恢复，报告退化状态并保留数据，禁止忙循环或伪报 ready。格式/协议新增先按 ADR 0006 版本化；本 ADR 不直接定义新 XML，也不更换核心依赖。

## 后果

正面：headless 与真机共享可测的窗口/输入语义；多屏、VT、空闲和故障不再是隐藏例外；输出身份、用户偏好与设备实例各有明确生命周期。

负面：增加状态机、坐标转换、拓扑回退和硬件测试成本；M2.5 不能以“驱动编译通过”结项；M4 的显示管理与 Shell 布局需协同实现。

影响面：`inox-compositor`、`inox-protocols`、`inox-config`、`inox-settings`、`inox-panel`、`inox-wallpaper` 与 `inox-integration`。不新增仓库或反向/横向 Cargo 依赖。

复审条件：引入多 GPU/多 seat、HDR/VRR、远程输出或新的渲染后端时，另写 ADR 说明新增状态和支持矩阵；不得让实验能力自动进入 supported。

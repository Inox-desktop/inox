# L2 真实后端硬件验收

本记录对应 accepted [ADR 0012](../adr/0012-output-input-and-frame-lifecycle.md)、
`proposed` [ADR 0019](../adr/0019-multi-output-topology-and-multi-gpu.md) 与
[ADR 0020](../adr/0020-fractional-scaling.md)，以及[验收规范](acceptance.md) O01–O04、H01/H02。
代码和 CI 不能替代硬件运行证据。

## 当前状态

- 实现范围：libseat；枚举 seat 上的每一块 GPU，每块用自己的渲染器驱动自己的 connector；
  多输出并排布局（含负坐标）、每输出独立的帧生命周期、libinput、软件光标、非整数缩放
  （`0.25..=8.0`，客户端经 `preferred_buffer_scale` 与 `wp_fractional_scale_manager_v1` 得知）。
- CI 范围：完整 feature 编译与 lint、帧状态机、模式排序、设备按键清理、共享 Wayland 场景与软件像素；
  另有多输出的虚拟拓扑与迁移（`tests/multi_output.rs`）与分数缩放的物理像素落点
  （`tests/fractional_scale.rs`），两者均为 E1+E3。
- E4：**未执行**。设备、驱动、内核、CI 发布物版本和原始日志均待验收者填写。
- **仍不在支持声明内**：跨 GPU 缓冲复制路径（PRIME，`linux-dmabuf` 的前置条件）、旋转、
  显示试用（15 s 未确认回退）、HDR/VRR、多 seat。**O02/O03 仍未通过**——虚拟拓扑与像素证据
  不等于真机热插拔与混合 DPI 客户端的结果。

## 准备

使用 CI 构建产物，在具有活动 VT 的本地用户会话运行，具备 logind 或 seatd 设备授权。
不要从另一个正在占用 DRM master 的桌面里把它当嵌套合成器启动。记录内核、GPU/驱动、
connector/mode、libseat 后端、显示器、键盘与鼠标型号及二进制提交 SHA。

显式 headless 只用于 CI。真实会话用 `inox-compositor --backend drm --socket inox-hardware`，
另一个同 UID 的控制终端通过该 socket 启动实际 Wayland 终端和至少三个客户端。
默认 `auto` 与 `drm` 都不会回落 headless；错误配置或设备不可用应得到非零退出，不能报告 ready。
启动日志必须先确认输出/模式，并在首次 page-flip 完成后才出现 physical ready。

## 操作与证据

| 场景 | 操作 | 必须观察 / 保留的证据 |
|------|------|----------------------|
| O01 启动与输入 | 启动三个应用，移动/点击/滚轮、输入文本、Alt+Tab、Ctrl+Alt+Fn | 真实画面与可见指针、正确焦点和按键，无重复 `+8`，正常滚动；截图/录像和原始日志 |
| O01 VT | 切离/切回各 10 次，包括按住修饰键时切离 | 暂停无设备提交；恢复重绘，无卡住按键/按钮，其他 VT 可操作；每轮结果与日志 |
| O01 热插拔输入 | 按住键或按钮时拔掉设备，连接另一套键鼠，含两键盘同时按同一键 | 能力变化正确，最后一个物理按下释放后才释放逻辑按键，无悬空 grab |
| O02 多输出（ADR 0019） | 接两块不同分辨率的显示器，配置为并排（其中一块用负坐标）；拔掉承载窗口的那块，再全部拔掉后逐个接回，共 20 轮 | 窗口与可操作入口迁移到存活屏；离线屏的配置保留；重接不重复创建面板；无屏时不忙循环、不把临时拓扑写成新偏好。截图/录像与每轮日志 |
| O02 多 GPU | 在既有 iGPU+dGPU 或双卡机器上让每块驱动各自的 connector | 每块设备只驱动自己的 connector，一块的拔插/恢复不牵动另一块；跨 GPU 的客户端缓冲能否显示必须如实记录（本版没有复制路径） |
| O03 混合 DPI（ADR 0020） | 两块屏分别 100%/200%，再试 125%/150%；跨屏移动窗口、popup 与指针 | 逻辑/物理坐标、命中、光标与 popup 对齐；记录真实客户端在 125%/150% 下的缓冲尺寸与清晰度（模糊即为未通过） |
| O04 空闲 / damage | 应用停止更新后观察，再触发窗口更新或指针移动 | 空闲不持续 page-flip；首帧、damage、恢复可唤醒；保存 DRM/性能工具原始数据 |
| O04 输出移除 | 拔掉唯一输出后等待，再接回；随后尝试另一 connector | 应用进程/连接保留，无屏无重绘忙循环；恢复可操作，旧层关闭后客户端重建，无重复面板 |
| O04 故障 | 在可控环境制造设备丢失或提交失败，保留诊断 | 不无限重试，暂时失败最多三次，page-flip 等待 2 秒超时；不把退化状态报告成成功启动 |
| 退出 | Super+Q、SIGTERM 各执行一次 | 退出码 0；设备与 DRM master 释放，VT 恢复可操作，无残留进程 |

软件光标应分别验证默认箭头、客户端 cursor surface/热点与显式隐藏。主题中的光标尺寸来自
`spacing.lg/xl`，颜色来自 `colors.background/text`；不要用「指针命中正确」替代「指针可见」。
运行期配置重载和显示试用事务尚未交付；只验证启动期输入、主题、平铺与 mode 配置。

## 结果登记

每个场景登记日期、验收者、设备矩阵、发布物 SHA、操作次数、实际结果和原始证据链接。
失败项另建缺陷并记录可复现步骤。没有执行或缺少证据一律保持未通过，不能以 CI 全绿代填。

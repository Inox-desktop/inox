# 验收报告模板

> 本文件是待填写模板，所有状态默认 `not-run`，没有实测结论。复制到 PR/Issue，发布时将填写后的报告归档并链接到 Release。字段不能留空；不适用必须给出理由。

## 范围与版本

- 任务 / PR / Release：待填
- 产品配置、目标里程碑、[验收规范](./acceptance.md)版本或提交：待填
- 基线 / 候选 tag 与 SHA：待填
- `Cargo.lock` 提交、发布 tag → 解析 SHA：待填
- 依赖清单、SBOM、运行时系统组件版本：待填
- 关联 ADR 及其状态 / 人类批准记录：待填
- 适用 ID；新增 / 受影响 / 完整回归范围：待填

## 环境与执行

- CI run / job URL、artifact 归档位置与保留期：待填
- runner 镜像/系统包、工具链、feature、软件渲染/真实后端：待填
- 私有 XDG 目录与 D-Bus 隔离方式、客户端/驱动/内核/字体/locale：待填
- 命令、用例数量、属性样本数与 seed、超时：待填
- 开始 / 结束时间（含时区）：待填
- E4：硬件配置 ID、CI 发布物校验和、人类执行者与硬件 Issue：待填
- 性能：参考设备、负载、采样数、预热、每轮原始数据与基线比较：待填

## 逐项结果

| 验收 ID | 证据等级 | 前置 / 操作 / 实际断言 | 状态 | 证据链接 / 缺陷 Issue |
|---------|----------|------------------------|------|----------------------|
| 待填 | 待填 | 待填 | not-run | 待填 |

- 未执行 / 阻塞 / 不适用项及原因、影响、责任人：待填
- 首次失败、重跑结果、基础设施故障认定与修复记录：待填
- 退出码、子进程/socket/FD 清理、故障注入后恢复结果：待填
- GUI 前后截图 / 差异 / 语义树与焦点轨迹：待填
- 敏感数据脱敏与人工样本说明：待填

## 结论与人类审查

- 可声明的结论（技术演示 / 组件通过 / 完整会话 / 发布候选）：待填
- 未解决 P0/P1/P2、已知限制与支持矩阵：待填
- 回退步骤与对应证据：待填
- 人类审查者、批准链接与日期：待填
- 最终结论：**未验收**

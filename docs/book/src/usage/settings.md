# 系统设置

运行 `inox-settings`，使用「应用」「取消」「全部恢复默认」管理草稿。
只保存实际改过的字段；文件被外部编辑时保留草稿并提示重新读取。
写盘失败会显示原因；多文件保存可能部分成功，各文件的状态分别处理。

当前尚无组件配置应用传输，因此「已保存」不表示当前会话已经生效。
新偏好由下次组件或会话启动读取；显示页不会实时切换显示模式。

## 壁纸

在「壁纸」页挑选 Inox 内置的壁纸，或选择「主题背景」（不显示图片）；也可以保留配置里手写的自定义
PNG/JPEG 路径。再选择填充、适应、拉伸、居中或平铺。可以添加各显示器的接口名和独立壁纸；
`*` 匹配其他显示器，没有覆盖项的显示器使用主壁纸。内置壁纸随发行版安装，设置应用不会下载图片；
自定义路径应是当前用户可读的现有文件。

## 输入法

在「输入法」页添加第一项 `/usr/bin/fcitx5`，之后每项填写一个参数；
参数直接传递给程序，不经 shell 解释，不要使用后台运行参数。
清空列表可禁用自动启动，保存后重新登录物理会话。
命令行的 `--input-method` 优先于此配置。
安装引擎、添加中文/日文方案、修改词库或切换快捷键，使用引擎自己的配置工具。
更多兼容信息见[输入法](input-methods.md)。

## 其他页面

- 外观与语言：浅色、深色、跟随会话，以及跟随环境、英文和中文。
- 面板：位置、尺寸、间距、预留空间、自动隐藏、图标、任务按钮、时钟及格式。
- 通知：显示位置与尺寸、超时、勿扰、操作按钮、锁屏隐私、等待队列及满队列策略。
- 键盘与鼠标：XKB 布局、变体、按键重复、轻触点击、自然滚动。
- 窗口布局：主区域比例、主窗口数量和间距。
- 启动器：搜索和图标选项，以及终端程序和逐项参数。
- 显示器：添加输出，设置接口、分辨率、刷新率、缩放和位置。两个位置均留空时自动排列。

数字可以直接输入；错误或未完成输入会阻止应用。长页面支持滚动，Tab / Shift+Tab
遍历可用控件，焦点自动滚入可见范围。所有页面提供英文和中文文案。

自定义合成器快捷键、网络、蓝牙、音频和账户管理尚未接入设置应用。

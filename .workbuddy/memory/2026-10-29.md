# 2026-10-29

## 实现「打开文件/链接」（xdg-open 的非门户那条腿）

背景：仓库此前**没有**任何 `xdg-open` / `OpenURI` / `mimeapps` 实现；`inox-notifications` 的
`Outgoing::FollowLink` 被显式丢弃，`inox-portal` 只是规划中的 crate。

决定：不新建 crate（新增 crate 需 ADR + 分层表 + 打包清单），把打开器放进 `inox-launcher`，
因为它是「按目标挑应用」的同一件事，且能直接复用 `desktop_entry` 与 `exec`（`Exec` 字段码展开
与「argv 永不变成 shell 命令」的性质因此自动继承）。

改动：
- `crates/inox-common/src/paths.rs`：新增 `ENV_CONFIG_DIRS`、`DEFAULT_CONFIG_DIRS`、
  `XdgEnv::config_dirs()`、自由函数 `config_dirs()`；把 `data_dirs`/`config_dirs` 的过滤逻辑抽成
  `search_path()` 与 `split_list()`；+3 个单测。
- `crates/inox-launcher/src/open/mod.rs`：`Target`（URI 按 `x-scheme-handler/<scheme>`，file: URI 转路径）、
  `Environment`（可注入的搜索路径快照）、`resolve()`（`mimeapps::candidates` → 定位 `.desktop` →
  `desktop_entry::parse` → `exec::argv`，注册但未安装的候选**落到下一个**）、`launch()`（detach spawn）、
  `run_cli()`（退出码 0/1/2/3/4）、`opener_arguments()`（argv[0]=`inox-open` 或 `--open`）。
- `src/open/mime.rs`：scheme 判定、`%XX` 解码、shared-mime-info `globs2`/`globs` 解析（纯文本，
  不读 `mime.cache`、不做 magic 嗅探）、glob 匹配（`*` `?` `[...]`、`cs` 标志、按 weight 取最具体）。
- `src/open/mimeapps.rs`：`mimeapps.list` 规范顺序（用户 config → config dirs → data dirs →
  `defaults.list`）、`Defaults` 优先于 `Added`、`Removed` 相减、首个文件赢；纯解析 + 合并。
- `src/main.rs`：多调用入口（在 `logging::init` 之后、Qt 初始化**之前**）——`inox-open …` /
  `inox-launcher --open …`，打开链接不付 GUI 工具包启动代价；`--exec-application` 分支改为基于
  `Vec<OsString>` 切片。
- 文案：`launcher.ftl` en-US / zh-CN 各 9 条 `launcher-open-*`。
- `src/catalog_tests.rs`：`referenced_ids()` 改为**递归**扫描 `src/`（否则 `src/open/` 里的 id 会被判成
  「目录有、代码没有」）；顺带发现测试里不能写以 `launcher-` 开头的字面量，改用「句子含空格」判定。
- 打包：`packaging/install.sh`、`packaging/aur/PKGBUILD.in`、`canary/PKGBUILD` 安装
  `inox-open -> inox-launcher` 符号链接。
- 文档：launcher README / AGENTS（新增 `src/open/` 与诚实缺口）、`docs/book` 的 components.md 与 roadmap。

验证（本机）：`cargo test -p inox-launcher --bin inox-launcher` 334 passed（1 ignored 是子进程自检）、
`cargo test -p inox-integration --test layering` 17 passed、`cargo clippy -p inox-launcher -p inox-common
--all-targets -- -D warnings` 干净、`cargo fmt --all --check` 干净。真实二进制冒烟：临时 XDG 树里
`--open notes.txt` → 启动 `/bin/true` 退出 0；不存在的路径 → 2；未知扩展名 → 3；无参数 → 1；
符号链接 `inox-open` 走同名入口；真实会话里 `--open https://example.org` 按 `~/.config/mimeapps.list`
选中 `google-chrome.desktop` 并退出 0。

环境坑（记下来省下次的时间）：
- `QT_QPA_PLATFORMTHEME=gtk3` 会让 `headless_tests::the_qml_window_loads_offscreen` 在没有 display 时失败，
  跑 launcher 测试要 `env -u QT_QPA_PLATFORMTHEME`。
- `/tmp` 只有 10M tmpfs，链接/doctest 会 `Bus error`：用 `TMPDIR=/home/rownix/.cache/inox-tmp`。
- `cargo check -p inox-launcher` 在前台会被杀（cxx-qt-lib 编译太慢/太重），必须 `run_in_background`。
